To use any of these mods, follow the following instructions:
1. Make a copy of the game files in a separate directory.
2. Download the relevant mod file - this is the main.pak file Bookworm Adventures uses to run the game.
3. Replace the existing main.pak in the copy of the game with this new file - make sure to rename the file to main.pak if it isn't already called that.
4. Note that esiwtin saves may be incompatible with mods, so I recommend making a copy of the user saves (found in C:\\ProgramData\Popcap Games), and to play games on new saves.
