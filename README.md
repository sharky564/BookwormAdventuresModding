To use any of these mods, follow the following instructions:
1. Make a copy of the game files in a separate directory.
2. Download and extract the relevant mod zip file - this is the main.pak file Bookworm Adventures uses to run the game.
3. Replace the existing main.pak in the copy of the game with this new file - make sure to rename the file to main.pak if it isn't already called that.
